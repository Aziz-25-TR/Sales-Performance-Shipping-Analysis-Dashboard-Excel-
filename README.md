# 📊 Sales Performance & Shipping Analysis Dashboard

## 📌 Overview 

This project analyzes salesperson performance and shipping methods using Excel to identify top performers, customer behavior, and sales trends.

---

## 🎯 Objectives

* Evaluate performance of each salesperson
* Identify top and lowest performers
* Analyze shipping modes and their impact on sales
* Provide insights to improve sales strategy

---

## 📊 Key Metrics

* Total Sales
* Average Sales per Transaction
* Number of Unique Customers

---

## 📈 Dashboard Features

* Sales by Salesperson (Comparison Chart)
* Top & Bottom Salesperson Identification
* Shipping Mode Analysis
* Interactive PivotTable Summary

---

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Data Analysis
* Data Visualization
